# Gemini: The Infinite Dimension — 9:16 모션그래픽 (15초)

기획안 「Gemini: The Infinite Dimension (무한한 상상의 확장)」을 Three.js 코드로 구현한 세로형(1080×1920, 60fps) 광고 모션그래픽입니다.
모든 프레임은 시간 `t`의 순수 함수(`renderAt(t)`)라서 브라우저 미리보기와 MP4 렌더 결과가 프레임 단위로 동일합니다.

```bash
npm install
npm run dev      # http://localhost:5173 미리보기 (Space 재생/정지, ←/→ 0.5초 이동, ?t=7 로 시작 위치 지정)
npm run audio    # out/audio.m4a  (신스 스코어 + CC0 SFX, -14 LUFS)
npm run render   # out/gemini-infinite.mp4  (H.264 1080x1920 60fps + AAC)
node scripts/render.mjs --stills 3.5,8.5,14.5   # 특정 시점 PNG 스틸
```

## 씬 구성 (src/timeline.js 하나로 영상·사운드 동기화)

| 시간 | 씬 | 구현 |
|---|---|---|
| 0–3s | 오프닝: 암흑 속 스파크 | 4-포인트 스파크 셰이더, 별가루 3,000개, 1.55s부터 초고속 줌인(easeIn) → 2.85s 폭발과 함께 네온 리퀴드(도메인 워핑 fbm)가 화면 중앙에서 상·하단으로 갈라지며 열림 |
| 3–7s | 초고속 확장 | 화면 하단의 Gemini 스타일 프롬프트 바에 키워드가 타이핑 → 4색 thinking 점 → 3D 타이포로 떠오름. 하단→상단으로 물결치며 올라오는 데이터 스트림 9,000개. 키워드 3개(「우주 도시 설계해줘」「시뮬레이션 돌려줘」「초고해상도 일러스트」)가 7겹 레이어 3D 타이포로 타이핑되며 등장 → 각 18,000개 입자로 쪼개져 사이버 도시 / 고리 행성 / 토러스 노트 조형물로 빌드업 |
| 7–12s | 클라이맥스(Drop) | 홀로그램 3레이어: ① 글래스모피즘 코드 패널(뒤) ② 54,000 입자 네온 플라워 + 덩굴 생태계(중간) ③ 빛의 속도로 도는 궤도 혜성(앞). 9:16 프레임이 반복되며 카메라로 돌진하는 터널(키네틱 옵티컬 일루전), 스피드 라인, 중앙의 골드·블루 회전 심볼 |
| 12–15s | 엔딩 & CTA | 모든 입자가 나선형으로 중앙 엠블럼에 수렴 → 메탈릭 엠블럼, 엠보싱 메탈릭 화이트 워드마크 + 라이트 스윕, 태그라인 「당신의 상상, 그 이상의 속도로.」, 펄스·샤인 다운로드 버튼 |

**Z축 레이어 (8개 뎁스):** 리퀴드 배경(z −60) · 스피드 라인 터널 · 9:16 프레임 터널 · 코드 패널(−6) · 보조 HUD 패널(−2.5) · 입자 플라워/형상(0) · 궤도 혜성(+0.6) · 중앙 심볼, 그리고 별가루가 전 구간에 깔림.

**오디오 리액티브:** 120 BPM 킥/스네어 타임라인(`KICKS`, `SNARES`, `HITS`)을 영상과 사운드가 함께 읽습니다. 킥마다 입자 크기·색, 블룸, 크로마틱 수차, 카메라 셰이크가 반응하고, 스네어마다 코드 패널 글리치, 히트(2.85s/7s/12.85s)마다 플래시와 렌즈 워프가 터집니다.

## Gemini 디자인 언어 반영
[Google Design — Illustrating the Gemini App](https://design.google/library/gemini-ai-visual-design) 및 2025년 4색 아이콘 리프레시를 참고했습니다.

- **컬러:** Google 4색(#4285F4 · #EA4335 · #FBBC04 · #34A853) + Gemini 그라데이션(#4285F4 → #9B72CB → #D96570). 스파크/엠블럼은 파랑 바탕에 위쪽 빨강·왼쪽 노랑·아래쪽 초록이 번지는 4색 그라데이션.
- **그라데이션 형태:** "앞쪽 가장자리는 선명하고 꼬리는 퍼지는" 규칙 → 프롬프트 바 테두리를 도는 빛, 리퀴드 파동의 가장자리.
- **원(circle)이 기본 형태:** 스파크 폭발 순간 한 점에 모였던 그라데이션이 4색 원형 리플로 퍼져나감.
- **모션:** 시작·끝이 명확한 방향성, 줌인 직전 살짝 뒤로 물러나는 anticipation → release, 4색 점이 회전하는 "생각 중(thinking)" 상태.
- **UI:** 둥근 알약형 프롬프트 바(「Gemini에게 물어보기」) — 키워드가 바에 타이핑되고(타이핑 효과음), 생각 중 점이 돈 뒤 3D 타이포로 떠올라 입자로 폭발.

## 사운드
`scripts/audio.mjs`가 같은 타임라인으로 직접 합성합니다: 서브 베이스 드론 + 벨 차임(오프닝), 킥·스네어·하이햇, D마이너 아르페지오와 사이드체인 베이스, 드롭의 7보이스 슈퍼소우 코드, 노이즈 라이저, 엔딩의 **오리지널** 4음 차임(D5–A5–F♯5–D6)과 D메이저 패드. 여기에 `.claude/skills/sound-effects`의 CC0 효과음(whoosh, impact, riser, glitch) 10개를 얹고 -14 LUFS로 마스터링합니다.

## 렌더링 규칙 (custom-motion 스킬 준수)
- 미리보기는 `requestAnimationFrame` 루프(오디오 시계에 동기화), 렌더는 프레임 정확 60fps
- 기본 이징 `cubic-bezier(0.25, 1, 0.5, 1)` (JS는 Newton 솔버, GLSL은 근사식)
- 입자·궤도·데이터 스트림·스피드 라인은 모두 정적 `BufferGeometry` + 셰이더 유니폼만 갱신 (프레임당 버퍼 업로드/객체 생성 없음), 코드 패널은 텍스처를 다시 그리지 않고 UV 스크롤
- `setPixelRatio(min(dpr, 2))`
